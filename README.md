# Desintoxicación Digital

App Android para usar menos el móvil: límites de WhatsApp, correo, periódicos y Cartelera,
pausa de intención, comodines, días especiales, desconexión total y estadísticas.

Cada cambio en `main` se compila solo (GitHub Actions) y se publica como versión nueva.
La app descarga las actualizaciones desde la última versión publicada:
`https://github.com/macipecosta/desintoxicacion-digital/releases/latest/download/desintoxicacion-digital.apk`
